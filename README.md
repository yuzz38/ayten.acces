# ayten.acces — лендинг именных аксессуаров для волос

Одностраничный сайт для мастерской **ayten.acces** (Подольск, отправка по всей России): именные крабики, бабочки, расчески, шкатулки и подарочные наборы с именем.

## Структура

```
index.html          — страница (10 блоков + шапка и подвал)
css/style.css       — стили, адаптив 320–1920 px
js/main.js          — меню-бургер, конструктор имени на canvas, слайдер отзывов, анимации
img/                — оптимизированные изображения: WebP 480/900 px + JPG-фолбэк, иконки, OG-картинка
video/process.mp4   — короткое видео процесса (≈220 КБ, без звука)
robots.txt, sitemap.xml, llms.txt, site.webmanifest, .htaccess — SEO/GEO и сервер
seo-keywords.md     — семантическое ядро и где какие ключи использованы
```

## Блоки

1. Первый экран с живым конструктором: имя выкладывается стразами на крабике, выбор цвета крабика и страз
2. Стена имён из реальных заказов
3. Каталог: что можно сделать именным
4. Наборы-бирки с ценами (1 200 / 2 590 / 3 990 ₽ / по составу) + «соберём свой»
5. Как создаём: видео и 5 шагов
6. Галерея распаковок
7. Поводы для подарка
8. Отзывы (слайдер: свайп, стрелки, точки, автопрокрутка)
9. Частые вопросы (FAQ + разметка FAQPage)
10. Финальный призыв к действию

Блока с картой нет — точного адреса нет, только город Подольск.

## Кнопки заказа

Все кнопки ведут в директ Instagram (`https://ig.me/m/ayten.acces`). По клику в буфер обмена копируется готовый текст заказа: из конструктора — с именем, цветом крабика и страз, из наборов — с названием набора.

## Перед публикацией

- [ ] Заменить домен `https://ayten-acces.ru/` на реальный: `index.html` (canonical, og, JSON-LD), `sitemap.xml`, `robots.txt`, `llms.txt`.
- [ ] **Заменить отзывы в блоке «Отзывы» на реальные** из директа или комментариев. Сейчас там шаблонные тексты для демонстрации вёрстки.
- [ ] Уточнить у заказчика состав наборов за 1 200 и 2 590 ₽ и цену большого набора.
- [ ] Желательно добавить запасной канал связи (Telegram / WhatsApp / телефон): Instagram в РФ открывается не у всех.
- [ ] Подключить Яндекс Метрику, добавить сайт в Яндекс Вебмастер и Google Search Console.

Сайт статический, сборка не нужна: достаточно загрузить папку на любой хостинг. Шрифты (Prata, Manrope, Marck Script — все с кириллицей) подключаются с Google Fonts.

Совместимость: iOS Safari 12+, Android Chrome, Chrome / Edge / Firefox / Safari / Яндекс Браузер. Учтены безопасные зоны iPhone и `prefers-reduced-motion`; поля ввода не вызывают зум на iOS.
