# Семантическое ядро ayten.acces

Кластеры ниже собраны по коммерческому интенту (запрос = готовность купить). Частотность проверить в Яндекс Вордстат перед запуском рекламы; приоритет — по логике спроса в нише персонализированных подарков.

## 1. Ядро (высокая конверсия) — title, H1, первый экран, каталог
| Запрос | Где использован |
|---|---|
| именной крабик | title, description, H1-подзаголовок, каталог, FAQ, JSON-LD |
| крабик с именем | meta keywords, alt, FAQ |
| крабик со стразами с именем / именной крабик со стразами | alt, каталог, JSON-LD |
| заколка с именем | keywords, title |
| именная расческа / расческа с именем на заказ | каталог, наборы, alt |
| именные аксессуары для волос | footer, JSON-LD, sec-head |
| персонализированные аксессуары для волос | footer, llms.txt |

## 2. Подарочный интент — блоки «Наборы», «Поводы»
- подарок с именем девушке / подруге / сестре / дочке
- именной подарок на день рождения
- персонализированный подарок
- подарок которого у неё точно нет / что подарить девушке у которой всё есть
- подарочный набор с именем
- именная шкатулка для украшений, именное зеркальце, именной кошелек

## 3. Сезонные — блок «Поводы» (усилить рекламой перед датами)
- подарок на 8 марта коллегам / девушкам
- подарки подружкам невесты, подарки на девичник
- подарки на выпускной / последний звонок
- новогодний подарок девушке с именем

## 4. Гео и доставка — title, description, meta geo, JSON-LD address
- именные аксессуары Подольск, подарок с именем Подольск
- именной крабик купить с доставкой по России

## 5. GEO (ответы нейросетей)
FAQ-разметка (FAQPage), llms.txt с фактами и ценами, разрешённые AI-боты в robots.txt, чёткие числовые факты (1 100 ₽, 3 990 ₽, состав наборов).

## Рекомендации после публикации
1. Заменить домен ayten-acces.ru на реальный во всех файлах (index.html, sitemap.xml, robots.txt, llms.txt).
2. Добавить сайт в Яндекс Вебмастер и Google Search Console, отправить sitemap.
3. Создать карточку в Яндекс Бизнесе (Подольск) и указать ссылку на сайт в профиле Instagram.
